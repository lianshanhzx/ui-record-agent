## 0. 页面结构事实（实测）

| 项 | 实测结果 |
| --- | --- |
| 布局 | 左侧可折叠树面板（标题「产品要素」，搜索框 + 3 个图标按钮），右侧页签区（默认空） |
| 左侧工具栏 | **图标按钮**，不是文字按钮：`el-icon-folder-add`=新增类型，`el-icon-document-add`=新增组件，`el-icon-delete`=删除；tooltip 才显示中文 |
| 树根/节点 | 根：产品公共要素（root1，dataTp=1）、产品个性化要素（root0，dataTp=0）；节点分组类型 elmtGrpgTp：0=要素类型、1=组件 |
| 树节点文本 | 渲染为「节点名 -」（带尾部减号），xpath 用 `normalize-space()='年龄限制'` 匹配不到，需 contains/去尾符 |
| 右侧页签 | 选中**类型**节点：仅「基本信息」；选中**组件**节点：「基本信息」+「产品要素」（tab id：`tab-first` / `tab-second`） |
| 基本信息字段 | 组件编号（disabled，自动生成/root1-root0）、组件名称、组件类型（prnNo，树形选择器）、序号；类型节点无「组件类型」字段 |
| 产品要素列 | 单选列、要素编码、要素名称、所属列表要素编码、要素类型、数据字典、数据组；10 条/页，实测 35 条 4 页 |
| 主要接口 | `prodElmtGrpgInf/list`（树/分组）、`prodElmtInf/query`（要素列表）、`prodElmtDtl/list`（修改回填）、`paramProperty/findProdDataPage`（要素名称远程搜索，pageSize=5） |
| 提示组件 | 业务错误多为 `el-notification`（右上），仅「修改未选行」是 `el-message--warning`；两者均为 fixed 定位，`offsetParent` 判定不可见 |

> 数据现状：树里除 2 个根外，还有 15 个父级（ZJLX401444）已不存在的组件被顶到根级显示；`root0` 同时作为 root1 的子节点出现（id=11）。属于存量脏数据，录制时应固定选具体组件，不要依赖“第 N 个根/子节点”。

## 一、左侧树结构交易

| 编号 | 交易 | 前置/显示条件 | 操作步骤 | 实测校验/反馈 |
| --- | --- | --- | --- | --- |
| T1 | 树关键字搜索 | 任意 | 在「搜索关键字」输入框输入（如「利率」）→ Enter | 树被过滤为 1 个命中节点「利率 -」；清空后恢复 |
| T2 | 展开/折叠节点 | 有子节点 | 点节点左侧展开箭头 | 展开后子节点以 18px 缩进渲染，再次点击折叠 |
| T3 | 选中节点加载右侧 | 任意非根/根节点 | 点树节点 | 类型节点→基本信息；组件节点→基本信息+产品要素，并触发 `prodElmtInf/query` |
| T4 | 新增类型 | dataTp=0（产品个性化要素）且选中节点为「要素类型」；根节点不显示 | 点 `el-icon-folder-add` | 弹窗「要素类型」：组件编号（自动 ZJLX6114，disabled）、组件名称*、组件类型、序号*；按钮 取消/保存 |
| T5 | 新增组件 | dataTp=1（产品公共要素）任意节点，或 dataTp=0 且选中类型节点 | 点 `el-icon-document-add` | 弹窗「要素组件」：组件编号（自动 ZJLX6113，disabled）、组件名称*、组件类型、序号*；按钮 取消/保存 |
| T6 | 删除分组 | 选中非根节点才显示删除图标 | 点 `el-icon-delete` | 有下级：`el-notification`“存在下级分类，不能直接删除”；无下级：`el-message-box`“确认删除记录信息?”（取消/确定）；被产品引用另提示“已经被XX产品编号引用” |
| T7 | 工具栏按钮可见性 | 随节点类型变化 | — | 类型根：新增类型+新增组件；组件：新增组件+删除；根：无删除（作为断言点） |

补充事实：
- 新增类型/新增组件的保存规则（需求文档 2.1）：序号必须正整数（“序号应为数字！”）、不能为 0（“序号应为非零数字！”）、组件名称/序号必填（“必填字段不能为空！”）；保存成功提示并刷新树、关弹窗。
- 新增类型弹窗标题是「要素类型」，新增组件弹窗标题是「要素组件」，二者表单字段一致，仅父级与分组类型不同（由入口决定）。

## 四、汇总交易清单（建议录制顺序）

1. 树：T1 搜索 → T2 展开 → T3 选中（类型/组件各一次）→ T4 新增类型 → T5 新增组件 → T6 删除（含“有下级”拦截 + 确认框取消）
2. 基本信息：B1 查看 → B2 改名称保存 → B3 序号校验负向 → B4 组件类型（观察/不录）
3. 产品要素：E0 查询 → E0b 重置 → E1/E2/E3 新增三段 → E4 修改 → E6 删除确认 → E7/E8 两个负向拦截

录制注意点：
- 图标按钮没有文字，语料/锚点用 class：`el-icon-folder-add` / `el-icon-document-add` / `el-icon-delete`，tooltip 文案仅作断言。
- 树节点文本带尾缀「-」，锚定用 `contains(normalize-space(.),'年龄限制')`，并在展开后再点。
- 页签用固定 id `#tab-first` / `#tab-second`；隐藏 tab-pane 里的同名字段会干扰 placeholder 定位，须 scope 到 `#pane-second`。
- 提示分两类：`el-notification`（右上）与 `el-message--warning`（顶部），回放断言按类名分别找。
- 存量数据大部分被产品引用，删除成功路径建议用 AT_ 前缀自建组件+要素，录完自行清理；避免动 年龄限制/产品相关标志 等真实分组。
- 树结构存在脏数据（15 个孤儿父级 + root0 重复挂载），不要用“第 n 个根节点/子节点”定位。
