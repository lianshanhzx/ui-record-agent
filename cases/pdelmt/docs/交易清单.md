## 五、录制约束与已知坑

- 树：XPath 不含节点名称；名称只作搜索输入；点击前断言匹配数=1 且可见；点击后比对组件编号/接口 elmtGrpgNo。
- 列表：查询与行定位用业务编码（elmtNo）；查询后断言可见行数=1；新增/修改/删除以接口 200 + 回查列表为断言；行选择点首列 `td`（radio label 不可见但可点）。
- 弹窗：`elmt-add-dialog` 内「要素名称」等 select 有隐藏输入副本（同 label 3 个 input，可见 1 个）→ 断言以「可见 1 个」为准，不用序号。
- 提示：`el-notification`（右上）与 `el-message--warning`（顶部）两类；fixed 定位不能用 offsetParent 判可见。
- 页面隔离：SPA hash 路由下 `goto` 同 URL 不会重载，未选行负向场景需 `page.reload()` 重置选中态。
- 数据：组件/要素新增删除成对自清理；基本信息 fixture `AT_BASE_LIST` 常驻，录制值幂等（同名/同序号重复保存）。
