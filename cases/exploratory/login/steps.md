# T00 登录页 - 步骤与元素清单

页面: `http://test.creditv5p2.tansun.com.cn/#/login?redirect=%2Fhome`（天阳科技 信贷统一门户）
截图: `shots/01-login-full.png`（多模态分析）

## 页面结构（多模态）
- 左侧: 3D 装饰图（无交互）
- 右侧登录卡片: Logo（天阳科技+信贷统一门户）+ 5 个输入项 + 登录按钮 + 2 个底部链接

## 登录步骤（实际最小流程，已验证）
| 步骤 | 动作 | 对象 | 值 | 说明 |
|------|------|------|-----|------|
| 1 | input | 用户名 | 701994 | |
| 2 | input | 密码 | 1 | |
| 3 | click | 登录 | - | POST /createToken → access_token → 落 localStorage → 跳转 /home（工作台） |

- 图形验证码/手机验证码/法人选择均**可跳过**（login_direct.js 长期实证：仅账号+密码登录成功）
- 登录成功 API: POST `.../tansun-tcp-sys/.../createToken`（返回 access_token）
- 登录态: access_token 落 localStorage，有效期 ~50min
