# 伙伴平台对接接口说明

> 来源代码：`src/services/partner-platform.js`（全部出站调用的唯一出口）。
> 更新日期：2026-09-16。

## 一、通用约定

| 项 | 值 |
|---|---|
| 基址 | `PARTNER_API_BASE`（env/config 可覆盖），缺省 `http://172.20.101.162:11001/api` |
| 认证 | 请求头 `access_token: <SSO JWT>`（优先转发 Vue 前端登录态 token；无登录态时回落 `PARTNER_ACCESS_TOKEN` 服务级 token） |
| 超时 | 30 秒（`AbortController` 中断） |
| 业务成功码 | `code = 200`（部分接口兼容 `code = 0`），非 200/0 抛 `PARTNER_NETWORK_ERROR_MSG` 并携带伙伴原始响应 |
| 响应容错 | HTTP 非 JSON（如网关 HTML 错误页）按 502 处理，错误详情截前 200 字符入 `partnerDetail` |

## 二、接口清单（共 5 个）

### 1. 项目列表 `POST /system/systemproject/list`

- 用途：批量推送对话框里选目标项目。
- 请求体：`{}`（空对象）。
- 消费方路由：`GET /api/v2/export/partner/projects`。
- 归一化：返回行取 `id ?? projectId ?? project_id` + `name ?? projectName`。

### 2. 系统懒加载树 `GET /system/system/lazySystemTree`

- 用途：项目下系统树（支持逐层懒加载与整树递归展开）。
- Query 参数：`projectId`（必填）、`menuType=1`、`from=0`、`searchName=`（空）、可选 `parentId`（缺省取根层）。
- 包装函数：
  - `listPartnerSystems(projectId, parentId?)` — 拉一层；
  - `listPartnerSystemTree(projectId, maxDepth=8)` — 自根向下按 `parentId` 并发展开成嵌套树，`isLeaf=true` 即停，`maxDepth` 防环。
- 消费方路由：`GET /api/v2/export/partner/systems`、`GET /api/v2/export/partner/system-tree`。

### 3. 菜单推送专用系统查询 `POST /system/system/getSystemNodeLevel`

- 用途：菜单推送前选择目标系统节点（POST、无参数，返回节点层级清单）。
- 消费方路由：`GET /api/v2/export/partner/menu-push/systems`。

### 4. 交易推送（核心）`POST /demand/demandtranscation/importDemand`

- 用途：把录制的交易（轨迹）推送到伙伴平台，V2.0/V3.x 批量与单条共用此端点。
- URL 可用 env `PARTNER_IMPORT_DEMAND_URL` 整体覆盖（联调/测试环境切换用）。
- 请求体（`transcationEventTypeList[]`，每个 entry）：
  - 顶层：`transcId`（轨迹 id）、`pageId`、`transcationName`、`systemId`、`projectId`、`transcationType=web`、`testFrame=playwright`、`transcationProperties`。
  - `transcationProperties[]` 三类节点：`page`/`popup`（页面级截图节点，rect=文档坐标）、`card/tab/wizard/object`（分区中间节点）、`ele`（控件操作节点）。
  - **`ele.rect` 坐标格式（2026-09-16 起）**：优先直出录制侧 `rect_norm`（0~1 相对所属截图）；录制期漏写的存量步骤在导出侧用所属截图尺寸换算归一化（弹窗=弹窗 rect 宽高、页面=contentWidth/Height 分母）；仅当轨迹完全无截图行时保留像素原值。
  - 出站适配（`toPartnerImportPayload`）：剥 `regionId`/`regionLabel`/`attr`/内部字段 `_shotW/_shotH`；`screenshot[]`（URL 数组）合并为 `screenCapture`（逗号串）；`type=section` 按配置改写为 `object`。
- 推送前自检（`preflightCheck`，只告警不阻断）：`undefined` 字段、page/popup 缺 `screenCapture`。
- 推送门禁：仅 `persistent_record_status='completed'`（已确认）可推；页面级覆盖校验缺失时按模式阻断。
- 消费方路由：`POST /api/v2/export/transactions-v3`（批量）、`POST /api/v2/export/trajectories/:id/transactions-v3`（单条）。

### 5. 菜单推送 `POST /system/umlElementData/importData`

- 用途：菜单树（系统树 Excel 爬取/UML 采集结果）推送伙伴平台。
- 请求体：`schemaVersion`、`systemNodeId`、`systemName`、`menuVersion`、`menus[]`。
- 消费方路由：`POST /api/v2/export/partner/menu-push`。

## 三、调用关系速览

```
Vue 前端（登录态 SSO JWT）
   │
   ├─ 选项目 ────────────► POST /system/systemproject/list
   ├─ 选系统 ────────────► GET  /system/system/lazySystemTree
   ├─ 菜单推送选系统 ────► POST /system/system/getSystemNodeLevel
   ├─ 推送交易 ──────────► POST /demand/demandtranscation/importDemand
   └─ 推送菜单 ──────────► POST /system/umlElementData/importData
```

## 四、样例报文

仓库样例文件 `docs/partner/samples/partner-push-wire-828.json` 为 traj 828（评级申请-选择客户及评级模板）经完整出站适配后的**实际 wire 报文**（即伙伴平台收到的内容）：1 个交易 entry、6 个 properties（page + popup + 4 个 ele 控件），控件 rect 均为 0~1 归一化坐标。
